# 当前流水线设计

目标是日语单主唱的乐谱再演唱。标注、演唱和目标音色分开保存，既可从歌曲开始，也可复用已有乐谱或 VR 导唱。源码只保留当前音频自动标注、VR 导唱、Seed-VC 音色渲染路径；旧设想见 [初版设计](history/DESIGN_INITIAL.md)。

| 阶段 | 输入 | 输出与约束 |
| --- | --- | --- |
| 分离 | 本地歌曲 | 主唱、伴奏和可选去混响人声，保留原时间轴 |
| 标注 | 人声、用户给定 BPM | Vocal2Midi ASR、TiFA、GAME；原始标注与 `score.vr.json`，不读取外部歌词或罗马音 |
| 参考 | 手动片段，或完整音源 | 原样冻结片段，或全曲扫描、SingMOS 评分、局部时长扩展和自动选择 |
| 导唱 | 乐谱、固定提示、VR 与日语 LoRA | 原生 EOS 短唱句；对齐后对异常段最多增加两次候选，不修改歌词 |
| 音色 | 冻结导唱、目标参考、Seed-VC | F0 条件 44.1 kHz 输出，移调 0、长度倍率 1，保留原生 float 音频 |
| 再对齐 | 换声结果、原乐谱音素 | 独立 TiFA 边界和警告，不沿用导唱时间边界 |
| 导出 | 换声片段、新边界、伴奏 | 有限变速、保护歌词主体的衔接；48 kHz WAV / MP3 人声、混音与不变速串联版 |

目标参考不进入 VR 生成条件。`guide_reference_run` 仅作为 VR 固定提示；`reference_run` 提供最终目标音色。导唱缓存独立于目标参考和 Seed 参数，因此可以用同一份表演更换声音。

输入、参考、源码、运行参数和权重均记录哈希。改变导唱条件产生新导唱任务；仅换目标声音复用导唱、产生新的转换。每个转换结果记录源哈希、参考哈希、种子、时长变化和输出哈希；失败保留日志，重跑只补缺失或损坏结果。

音质与长度的参考排序是启发式优化，不保证找到全局最优，也不测音色相似度。结构覆盖、强制对齐和数值检查只能排除一部分错误；不能据此证明咬字准确、声线相似或演唱自然。源分离存在串音、叠唱或混响时，自动片段也可能受影响。

数据、模型缓存、本机配置与试听结果在 Git 忽略目录中。主仓库保留代码、模板、测试、模型来源和 LoRA；整理前快照和历史音频无需参与日常执行。

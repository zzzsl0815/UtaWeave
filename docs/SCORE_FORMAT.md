# 乐谱中间格式 v0.1

权威时间基准为全曲源音频的秒时间。MIDI 是可导出的音符视图；读音、呼吸、音素、量化前的真实时值和出处保存在 JSON 中。

| 字段 | 含义 |
|---|---|
| `schema_version` | 当前为 `0.1` |
| `timebase` | 固定 `source_audio_seconds` |
| `song` | id、标题、语言、原音频总时长 |
| `tempo_map` | `time_seconds`、`bpm`、来源；不覆盖实测音符时间 |
| `phrases` | id、原歌词、读音、全曲起止时间 |
| `units` | mora／rest／breath 单位，关联 phrase，包含文字和全曲起止时间 |
| `notes` | 音符全曲起止时间、MIDI 音高、所属 unit；休止音高为 `null` |
| `phones` | 音素、所属 unit、全曲起止时间 |
| `breathing` | 标注状态与事件；`unannotated`＋空数组不表示没有呼吸 |
| `provenance` | 源音频、标签、模型、候选读音与处理版本的出处和哈希 |
| `warnings` | 未解决的时钟、读音、音高等问题，不静默清除 |

一个 mora 可有多个音符；每个音符必须唯一属于一个单位。普通 MIDI 的合法音高0与模型把0当作休止的约定要区分：标准格式用 `null` 表示休止，VR 适配器再作转换。`vr_duration_token` 是可选的后端扩展，不能替代真实起止时间。

数据约束：有限数值；正时长；事件不越出全曲；首版仅一条主唱时间线，无内部重叠；id唯一；音符／音素在所属单位内；每个单位都有完整音符时长覆盖；歌词单位不以休止音高充当有效音符。极短音素还需单独诊断，结构通过不能证明真实正确。

当前 `validate-score` 实现上述主时间线与单位所属检查，并要求呼吸标注状态显式提供。节拍图编译、真实音频与歌词一致性、呼吸检测以及 MIDI 导出尚未实现。

旧格式导入需要选择 `source-seconds` 或 `source-samples`。对存在冲突的记录，选择只决定本次导入使用哪条时钟；不证明该时钟正确，也不修改旧数据。局部时间通过明确起点转换成全曲时间，原标签与哈希保留在 provenance 中。

每次改谱另存新版本，模型条件从该版本重新编译；读音、音符和目标声线不混入一个不可追踪的 prompt 文本。

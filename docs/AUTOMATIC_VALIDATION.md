# 自动检查与保留范围

`utaweave render` 调用 `song2voice.rendering.pipeline`，从冻结的 VR 乐谱和已选参考执行生成、生成后对齐、有限重试、选择、Seed-VC 换声、再次对齐与导出。无逐曲手工改词、读音候选替换或低质量片段删除。

- 生成：短唱句、原生 EOS、CFG=2、10 个扩散步、FP32 权重与 BF16 autocast。默认 batch=4。
- 分句：优先使用测得的静音边界。分离人声有伴奏串音时，可使用对齐歌词间至少 150 ms 的空隙，保留两侧各 35 ms 余量并记录来源；在最大时长内优先合并不足 500 ms 或缺少两个时钟锚点的短片段，逐项核验乐谱单元覆盖。
- 对齐：对固定音素序列做 TiFA 强制对齐，检查音节压缩、停止长度上限及速度偏差。
- 时钟：以完整歌词首尾边界映射到原曲，未知音高或短单元不豁免于边界约束。单个持续元音也可提供两个边界，记录为 `single_unit_endpoints`，仍执行相同速度限制；整段不足 30 ms 或边界非有限值时报告具体片段。源标注不足 30 ms、生成超过 80 ms 的单元记录为 `expanded_units` 并参与有限重试。
- 重试：异常片段额外采样两个候选，按相同的长度、对齐和压缩指标选择；保留所有尝试，不改乐谱。
- 换声：固定 F0 条件、移调 0、长度倍率 1；检查非静音、有限值、时长变化及输出哈希。换声后重新对齐，不复用 VR 边界。
- 整曲：限幅变速范围 0.8–1.25；优先在歌词之外的低能量区衔接，保护对齐歌词主体；不能安全拼接时停止并报告。
- 衔接：若下一句从采样点零就开始发音，两个音频未必有共同的非歌词重叠区。此时在歌词间隙内分别淡出/淡入各自可用的非歌词边缘，并记录 `independent_non_lyric_fades`；真正重叠的歌词主体仍然阻止导出。
- 导出：核验 WAV / MP3 可解码、采样率、有限值、峰值、文件哈希以及原曲时钟总长度。

这些检查不是歌词准确率、独立质量指标或听感认证。强制对齐可以将错误文字对齐到音频，所以对齐成功也不代表文字正确。

整曲前奏/间奏/尾奏的伴奏残留可能被 ASR 识别成元音，并进一步被音高模型赋予音符。短片段合并和单音节对齐修复的是工程边界，不能判定这些标签是否真实；需保留原始标注并报告待复核区间，不能靠删除难处理的片段宣称质量提升。

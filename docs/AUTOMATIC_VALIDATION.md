# 自动检查与保留范围

`utaweave render` 调用 `song2voice.rendering.pipeline`，从冻结的 VR 乐谱和已选参考执行生成、生成后对齐、有限重试、选择与导出。无逐曲手工改词、读音候选替换或低质量片段删除。

- 生成：短唱句、原生 EOS、CFG=2、10 个扩散步、FP32 权重与 BF16 autocast。默认 batch=4。
- 对齐：对固定音素序列做 TiFA 强制对齐，检查音节压缩、停止长度上限及速度偏差。
- 重试：异常片段额外采样两个候选，按相同的长度、对齐和压缩指标选择；保留所有尝试，不改乐谱。
- 整曲：限幅变速范围 0.8–1.25；优先在歌词之外的低能量区衔接，保护对齐歌词主体；不能安全拼接时停止并报告。
- 导出：核验 WAV / MP3 可解码、采样率、有限值、峰值、文件哈希以及原曲时钟总长度。

这些检查不是歌词准确率、独立质量指标或听感认证。强制对齐可以将错误文字对齐到音频，所以对齐成功也不代表文字正确。

旧实验中的修复过程保留在 `docs/history/`，当前命令不依赖原来的 `work/` 或训练目录。

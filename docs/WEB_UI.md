# 可视化工作台

工作台只调度 VR＋原生 Seed-VC 推理，不加载融合训练代码。所有模型和路径在服务器配置，浏览器负责输入、乐谱核对、进度与试听。

## 启动

先完成 [运行指南](QUICKSTART.md) 的模型与环境准备，然后在调度环境安装界面依赖：

```bash
.venv-svc/bin/pip install -e '.[ui]'
cp configs/web.example.json configs/web.local.json
# 按本机修改 web.local.json 的路径
.venv-svc/bin/utaweave serve --config configs/web.local.json --port 8770
```

浏览器打开 `http://127.0.0.1:8770/`。远程部署可在自己的电脑执行 `ssh -L 8770:127.0.0.1:8770 USER@SERVER`，再访问本机同一地址。服务默认只监听回环地址；这是个人本地工作台，没有多用户账户系统，不应直接开放到公网。

`web.local.json` 的路径相对于配置文件解析：

| 字段 | 用途 |
| --- | --- |
| `workspace` | 上传、任务记录和结果；每个任务独立目录 |
| `render_config` | 现有 VR、LoRA、固定导唱参考、TiFA、Seed 配置 |
| `reference_runtime` | 人声分离、去混响、SingMOS 环境 |
| `annotation_config` | Vocal2Midi 模型位置与标注参数；任务会覆盖输入、输出和 BPM |
| `labeling_python` | 安装了标注依赖及 `pyopenjtalk` 的解释器，用于标注和日语读音 |
| `netease_bridge` | 本仓库 `scripts/netease_bridge.cjs` |
| `netease_api_module` | 已安装网易云 API 模块的 `main.js`，需提供 `login_status` 和 `song_url_v1` |
| `credential_file` | 可选，仅服务器读取的 Cookie 文本文件路径；不在页面填写或上传 |

当前机器使用现有 NeteaseCloudMusicApi 4.28.0 模块，本仓库只提供适配器，不包含该模块、登录凭据或采集数据库。沿用已经配置好的模块即可；没有该模块时仍能上传本地原曲/参考、读取歌词链接和使用 MIDI。音频导入会检查完整文件与账户可用状态；获取失败时显示错误，不以试听片段冒充完整歌曲。

需要关掉 SSH 后继续提供页面时，可以用 `tmux` 运行上述服务，或使用已有进程管理器。推理任务作为独立进程启动，关闭浏览器或断开 SSH 不会中断已提交任务；机器重启仍会中断。重开页面可以从“最近任务”恢复显示。

## 有原曲

1. 输入网易云歌曲链接，或上传本地音频，填写 BPM。链接会提供原曲音频和歌词；本地音频也可以配上歌词链接/文本。
2. 点击“准备乐谱”：分离人声与伴奏，运行音频自动识别、TiFA 对齐和 GAME 音符提取。
3. 查看音符预览、歌词原文和逐单元读音。这里显示的是自动标注，不是人工真值。网易云歌词作为核对依据，不会未经对应就覆盖音频标注。
4. 可以修正每个单元的假名读音，音符与时间保持不变。需要修改旋律时走 MIDI 入口；当前表格不是完整的音符拖动编辑器。
5. 选择目标音色，确认乐谱后生成。

BPM 目前需要用户提供。人声分离、歌词识别和对齐仍可能有错误，界面不会把“自动处理完成”标成“乐谱准确”。

## 只有 MIDI 和歌词

1. 上传 `.mid` / `.midi`，选择单声部旋律轨。打击乐轨不参与；所选轨中存在复音会被拒绝，不能把钢琴和弦当成歌声旋律。
2. 粘贴日语歌词或 LRC，也可以从网易云链接读取；MIDI 已有歌词事件时可直接导入。
3. 程序排除带冒号的作词、作曲等署名行，再转换日语读音，按拍音给出顺序分配草稿。若字数和音符数不同，会显示空项及未分配的读音。仍有超额拍音且未经修改的草稿不能直接提交生成；需要结合原文调整，不会自动把尾部歌词补唱出来。
4. 在逐音符表中调整对应。填写假名；一个音符可以填多个拍音（如 `きみ`）。一字多音时，首音符填读音，后续连续音符填 `-`；不能跨休止延音。不演唱的音符可填 `SP`。长音也可填写明确元音。
5. “试听旋律”用合成音播放前 30 秒，检查音高和节奏；它不是 VR 生成结果。可先下载含标准 MIDI `lyrics` 元事件的文件，原有音符、轨道和速度事件保持不变。导出编码为 UTF-8。
6. 确认读音与对应，选择参考音色，再生成演唱。伴奏可选，不需要原始人声录音。

仅凭纯文本和 MIDI，无法唯一确定正确的歌词起点、连音和一字多音关系。因此自动分配只是可编辑草稿，不能替代人工核对。日语假名读音是当前主要支持范围；英文/中文的 MIDI 歌词转换尚未验证。

MIDI 的 tempo map 用于计算真实秒数；VR 的离散音符类别按支持的整数 BPM 近似量化。超出 1–255 的速度先做倍速/半速记谱换算，例如 278 BPM 转为 139 BPM，并根据原始秒数重新量化拍值；原 MIDI、音高和实际起止时间不变。变速作品会显示提醒。加载 GPU 模型前会检查条件时长，实际 VR 提示还会核对 BPM 标记，避免上游静默回退到 120 BPM。

当前短句规划依赖安全的歌词间隙，连续超过 14.5 秒且无可切分间隙的乐句会报错，应先在 MIDI 编辑器中整理呼吸与句间休止。

为了容纳生成前后余量，首音符不足 0.5 秒时整条时间轴会补足到 0.5 秒，末尾留 1.5 秒；可选伴奏按同样偏移对齐。MIDI 模式创建的静音时间轴缓冲只用于切句与整曲导出，不是原始人声，不进入 VR/Seed 的声学条件或响度匹配。

## 音色参考与生成

仍然只有两种处理方式：

- 手动：上传 1–25 秒已经剪好的单人清唱，保持片段本身，不重新评分。
- 自动：使用原曲、另一首网易云歌曲或上传的完整音源，分离、连续切片，再平衡 SingMOS 音质和有效人声时长。

VR 的固定导唱参考仍来自服务端 `render_config.guide_reference_run`；目标参考交给 Seed-VC。界面默认沿用可用流水线的 Seed 30 步、CFG 0.7，可以在生成设置中调整。

模型推理任务串行使用 GPU，MIDI 解析和读音准备不占用 GPU 队列。进度显示实际阶段，以及 VR 提供的已生成句数；不以动画代替真实完成度。停止按钮终止该任务进程组；失败后可查看日志、修改读音/参考并重新生成。相同音符与设置可复用导唱缓存。

## 结果与文件

完成后提供混音、纯人声和原速串联试听，支持拖动、唱句跳转及切换音轨保留位置。MP3 用于整曲预览，原生 WAV 保留供下载。所选参考单独显示，并在自动模式下展示 SingMOS 分数。

`workspace/jobs/JOB_ID/` 保存准备后的乐谱、原文、参考选择、推理配置、阶段日志与导出结果。`score.vr.json` 和带歌词的 MIDI 可以单独下载。浏览器只可访问任务内允许的媒体/报告文件，不提供配置或任意服务器文件下载。公开 Git 仓库不包含上传、Cookie、原始歌曲或生成结果。

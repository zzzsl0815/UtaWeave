# 自动校验与故障回归

每个修复进入脚本及回归测试，不维护针对某首歌的手工修订表。当前推理实验入口为 `work/run_render_validation.py`，读取已冻结的乐谱、参考选择记录及本机运行配置，自动执行生成、生成后对齐、有限重试、选择与导出。歌曲下载和标注仍是独立阶段。

## 数值边界与歌词完整性

ROSVOT 的 float32 音符边界可能与 TiFA 的十进制词边界相差亚微秒。求交前仅将相差不超过 **10 微秒**的音符边界吸附到原词边界，词的起止、歌词、罗马音及音素不改变。真实10毫秒短音节、音节内部的真实短音符和清音区间仍保留。这个容差处理数值精度，不是听感过滤阈值。

修复输出使用独立版本目录，记录父乐谱哈希、代码哈希、边界调整及修复前后时长。原始歌词单位的身份、顺序及时间必须完全一致。补音高仅使用已有的自动F0证据规则；证据不足时保留未知状态。

## 生成前校验

源乐谱和实际编译后的分段条件都需要通过以下检查，然后才加载GPU模型：

- 数组长度、合法音高、时值token、音符所属词索引与顺序。
- 每个原词都有音符映射，每词及全段的实测时长守恒。
- 不允许亚数值精度碎片被量化成额外音符。
- 真实短词、未知音高和较大的量化时长偏差作为警告保留，不丢句。

参考音频、模型适配器、乐谱、配置及编译代码均记录哈希。输入或代码改变时，禁止直接复用原有生成缓存。批次随机种子与参数保存在结果中。

## 生成后自动处理

用冻结乐谱中的日语与英文音素定位生成音节。长度上限、极短或过度压缩音节、异常速度比触发有限重试；每处最多增加两个候选，使用统一规则选择，并保留全部尝试。不会通过改歌词或强制延长EOS来消除警告。无法安全拼接时报告失败，保留输入，不删除该句来伪造整曲成功。

导出校验覆盖音频可解码、有限数值、削波、整曲时长和接缝对齐歌词主体保护。

## 检查结论的边界

`valid_for_render` 只表示数值条件可用。对齐分数、零警告、文件完整均**不证明音色自然、发音正确或演唱成功**。输出保留 `quality_status=not_assessed`，源标签中的不确定项与生成警告分别记录。用户反馈的失败版本保留诊断，不作为成功案例。

运行回归测试：`python -m unittest discover -s tests -v`。测试包括浮点边界漂移、重复修复幂等性、真实短音节保护、时长守恒、损坏输入阻断、英文保留、重复F0补全的历史保护，以及时值与原生VR的兼容性。

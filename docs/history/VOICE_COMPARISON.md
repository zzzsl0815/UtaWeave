# 音色后端与参考选择的历史对照

此前用相同的 VR 导唱和目标参考比较 Seed-VC、HQ-SVC、SoulX-Singer-SVC。项目内试听认为 Seed-VC 的音色相似度与自然度最好，因此当前主流程只保留原生 Seed-VC。该选择来自有限样本主观试听，不是通用模型排名。

参考选择曾比较固定时长和自动策略，最终采用音质与有效人声时长的平衡选择；当前仍支持手动提供已剪好的参考。现行规则和使用方法见 [参考准备](../REFERENCE_PREPARATION.md) 与 [Seed-VC](../VOICE_CONVERSION.md)。

旧的多后端、固定时长对照命令、模型缓存和试听页面不属于当前发布。不要使用历史配置启动现行程序。

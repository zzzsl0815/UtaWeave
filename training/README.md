# 已训练模型的归档记录

本目录保存选定 LoRA 的训练参数及语料规模摘要，不上传音频或歌词。模型的精确张量和来源哈希在 `weights/` 与 `manifests/models.lock.json`。

当前仓库的可运行范围是推理流水线；完整语料采集、训练语料修复和多轮训练执行器仍保存在原工作区，没有宣称搬迁成通用训练入口。`r64.recipe.json` 保存本次训练时使用的关键参数和实际统计，便于后续实现训练入口或做对照实验。

请区分两套标签：r64 训练使用当时经过参考罗马音核验的数据；当前歌曲推理默认只用音频，不再加载参考罗马音。当前流水线跑通并不代表使用它重新训练的模型已经验证。

# 已发布 VR LoRA 的训练记录

本目录只保存已发布日语 LoRA 的训练参数与语料统计，不提供融合训练入口。精确张量、配置和来源哈希见 `weights/` 与 `manifests/models.lock.json`，r64 配方见 [r64.recipe.json](r64.recipe.json)。

主流程是乐谱 → VR 导唱 → 原生 Seed-VC 换声。VR 和 Seed 均以推理模式加载；不需要训练转换器，也不加载失败融合实验的权重。过去的融合试验没有通过试听验收，因此不随本次主流程发布。

已有 VR LoRA 的采集、标注、修复和训练执行器来自原训练工作区；本目录的参数记录不能替代完整可复现的训练实现。r64 训练使用当时经过参考罗马音核验的数据，当前推理默认只根据音频标注。自动标注跑通不代表歌词和音符全部正确。
